## FAQ

### What is XCutors?

XCutors is a curated package for Windows that bundles several popular Roblox script executors and a universal loader into a single download, simplifying setup and management.

### Is this safe to use?

All included executors are from their respective official developers. The loader itself is open-source and scans for known threats. Users should always exercise caution and use secondary accounts when testing scripts.

### Which executors are included?

The collection currently includes Volt, Synapse Z, Potassium, Wave, and the xcutors universal loader. Check the repository for the latest supported versions.

### Do I need to install them separately?

No, the XCutors loader manages all bundled executors. You simply download the one package and use the loader to select which executor to run.

### What kind of scripts can I run?

You can run any standard Lua script designed for Roblox game environments. This includes UI modifications, automation scripts, and visual enhancements.

### Why do I need to run as administrator?

Some executors require elevated privileges to properly interact with the Roblox game client process for script injection. Running as admin ensures full functionality.

### How do I update the executors?

The xcutorsLoader will notify you if updates are available for any bundled executor. You can then update them directly through the loader interface.

### Does this work on Mac or Linux?

No, XCutors is designed and tested exclusively for the Windows operating system (Windows 10 and above) as the included executors are Windows-native applications.
